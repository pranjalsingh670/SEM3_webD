PROBLEM 1: EIGENVALUES AND MATRIX DIAGONALIZATION
--------------------------------------------------------------------------------
Consider the 3x3 symmetric matrix A:
        [ 4  1  1 ]
    A = [ 1  4  1 ]
        [ 1  1  4 ]

Part (a): Find the characteristic polynomial and all eigenvalues of A.
Solution:
  The characteristic equation is det(A - λI) = 0:
    det [ 4-λ   1     1   ]
        [  1   4-λ    1   ] = 0
        [  1    1    4-λ  ]

  Applying column operations (C1 -> C1 + C2 + C3):
    Factor out (6 - λ):
    (6 - λ) * det [ 1   1   1 ]
                  [ 1 4-λ   1 ]
                  [ 1   1 4-λ ] = (6 - λ)(3 - λ)^2 = 0

  Eigenvalues:
    λ1 = 6 (Algebraic multiplicity = 1)
    λ2 = 3 (Algebraic multiplicity = 2)

Part (b): Determine orthonormal eigenvectors corresponding to λ1 and λ2.
  For λ1 = 6:
    (A - 6I)v = 0 yields v1 = (1/√3) * [ 1, 1, 1 ]^T

  For λ2 = 3:
    (A - 3I)v = 0 yields x + y + z = 0
    Choosing two orthogonal vectors:
    v2 = (1/√2) * [ 1, -1, 0 ]^T
    v3 = (1/√6) * [ 1, 1, -2 ]^T

PROBLEM 2: GRAPH THEORY & DIJKSTRA'S SHORTEST PATH ALGORITHM
--------------------------------------------------------------------------------
Given an undirected weighted connected graph G = (V, E) with vertex set
V = {A, B, C, D, E, F} and edges:
  (A, B): 4,  (A, C): 2
  (B, C): 1,  (B, D): 5
  (C, D): 8,  (C, E): 10
  (D, E): 2,  (D, F): 6
  (E, F): 3

Compute the shortest path from Source A to Destination F:

Execution Trace:
  Iteration 0: Distances = {A: 0, B: ∞, C: ∞, D: ∞, E: ∞, F: ∞}, Visited = {}
  Iteration 1: Visit A (dist 0). Update neighbors:
               Dist(B) = min(∞, 0+4) = 4
               Dist(C) = min(∞, 0+2) = 2
  Iteration 2: Visit C (dist 2). Update neighbors:
               Dist(B) = min(4, 2+1) = 3 (improved path via C!)
               Dist(D) = min(∞, 2+8) = 10
               Dist(E) = min(∞, 2+10) = 12
  Iteration 3: Visit B (dist 3). Update neighbors:
               Dist(D) = min(10, 3+5) = 8 (improved path via B!)
  Iteration 4: Visit D (dist 8). Update neighbors:
               Dist(E) = min(12, 8+2) = 10 (improved path via D!)
               Dist(F) = min(∞, 8+6) = 14
  Iteration 5: Visit E (dist 10). Update neighbors:
               Dist(F) = min(14, 10+3) = 13 (improved path via E!)
  Iteration 6: Visit F (dist 13).

Final Result:
  Shortest Path: A -> C -> B -> D -> E -> F
  Total Weight / Distance: 13 units

PROBLEM 3: ASYMPTOTIC RECURRENCE RELATIONS
--------------------------------------------------------------------------------
Solve T(n) = 3T(n/2) + O(n log n) using Master Theorem:
  Here a = 3, b = 2, f(n) = n log n.
  log_b(a) = log_2(3) ≈ 1.585.
  Since f(n) = O(n^(1.585 - ε)) where ε ≈ 0.585, Case 1 of Master Theorem applies.
  Therefore, T(n) = Θ(n^(log_2(3))) ≈ Θ(n^1.585).
